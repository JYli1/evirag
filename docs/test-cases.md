# EviRAG 测试用例

## 1. 注册登录

| 编号 | 场景 | 步骤 | 预期 |
| --- | --- | --- | --- |
| A1 | 邮箱验证码注册 | 打开注册页，输入邮箱，发送验证码，填写验证码和密码 | 注册成功并进入工作台 |
| A2 | 验证码错误 | 使用错误验证码注册 | 返回统一错误，不暴露邮箱是否已注册 |
| A3 | 登录成功 | 输入邮箱和密码登录 | 获得 JWT，跳转工作台 |
| A4 | 账号禁用 | 管理员禁用账号后再次登录 | 登录失败或 token 失效 |

## 2. 知识库与文档

| 编号 | 场景 | 步骤 | 预期 |
| --- | --- | --- | --- |
| K1 | 创建知识库 | 在左侧栏输入知识库名称并创建 | 知识库出现在列表中 |
| D1 | 上传 TXT/MD | 上传 `.txt` 或 `.md` 文件 | 文档状态先处理中，随后就绪 |
| D2 | 上传 DOCX/PDF | 上传 `.docx` 或 `.pdf` 文件 | 文本被解析、切片并入库 |
| D3 | 上传不支持格式 | 上传非 PDF/TXT/DOCX/MD 文件 | 返回格式错误 |
| D4 | Embedding 失败 | 配置错误 embedding key 后上传文档 | 文档状态失败，展示 `EMBEDDING` 和原始错误摘要 |

## 3. RAG 问答

| 编号 | 场景 | 步骤 | 预期 |
| --- | --- | --- | --- |
| R1 | 普通问答 | 对已就绪知识库提问 | 中间区域流式显示回答 |
| R2 | 引用证据 | 查看右侧引用区 | 展示 Top-K 片段、来源、相似度 |
| R3 | 低相关性 | 提问与知识库弱相关问题 | 仍展示检索结果，并标记相关性较低 |
| R4 | Query Rewrite | 先问模块介绍，再问“那它有什么缺点” | 检索问题被改写，用户原问题不被替换 |
| R5 | 空知识库 | 未上传文档就提问 | 提示当前知识库没有可检索文档或无匹配片段 |

## 4. 管理员面板

| 编号 | 场景 | 步骤 | 预期 |
| --- | --- | --- | --- |
| M1 | 普通用户访问管理页 | USER 账号访问 `/admin` | 前端路由拦回工作台，后端返回 403 |
| M2 | 管理员统计 | ADMIN 账号访问 `/admin` | 显示用户数、知识库数、文档数、问答次数 |
| M3 | 配置状态 | 查看配置状态区域 | 只展示是否配置，不显示 API Key 明文 |
| M4 | 用户禁用 | 管理员禁用普通用户 | 用户状态变为禁用，并写入审计日志 |
